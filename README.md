The dog has a point, is the thing. A kid does homework at the kitchen table, a sandwich gets made at the same table, page two picks up peanut butter, and from dog height that essay is legally a snack. Nobody ever sat this dog down for the homework talk. The program writes the dog's one line of testimony to the output file, checks it fits the 200 character limit first, and that is the entire entry.

## Run it

```sh
node --experimental-strip-types main.ts
```
